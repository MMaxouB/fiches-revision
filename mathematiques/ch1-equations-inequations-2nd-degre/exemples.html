Ch1Résoudre ax2+bx+c=0

Toujours : identifier a,b,c, calculer Δ, puis choisir la formule selon le signe de Δ.

Δ > 0 · racines entièresRésoudre x2+3x−4=0.
  1. On identifie a, b, c
    a=1b=3c=−4
  2. On calcule le discriminant
    Δ=b2−4ac=32−4×1×(−4)=9+16=25
  3. Δ>0 : deux solutions
    x1=−3−252=−3−52=−4
  4. x2=−3+252=−3+52=1
Conclusion
S={−4;1}
Δ > 0 · racines avec √Résoudre 3x2+4x−1=0.
  1. On identifie a, b, c
    a=3b=4c=−1
  2. Discriminant
    Δ=42−4×3×(−1)=16+12=28
  3. On simplifie la racine
    28=4×7=27
  4. Les deux solutions
    x1=−4−276=−2−73
  5. x2=−4+276=−2+73
Conclusion
S={−2−73;−2+73}

Le cours écrit 3x2+4x−4 mais son calcul Δ=28 correspond à −1 : c'est cette équation. On simplifie la fraction en divisant le numérateur et le dénominateur par 2.

Δ > 0 · solution fractionnaireRésoudre 2x2−x−6=0.
  1. On identifie a, b, c
    a=2b=−1c=−6
  2. Discriminant
    Δ=(−1)2−4×2×(−6)=1+48=49
  3. Les deux solutions
    x1=1−74=−32
  4. x2=1+74=2
Conclusion
S={−32;2}

Attention : −b=−(−1)=+1.

Δ = 0 · solution doubleRésoudre 4x2−12x=−9.
  1. On passe tout à gauche
    4x2−12x+9=0
  2. Discriminant
    Δ=(−12)2−4×4×9=144−144=0
  3. Δ=0 : une seule solution
    x0=−b2a=−−122×4=128=32
Conclusion
S={32}
Δ < 0 · aucune solutionRésoudre −3x2+x−2=0.
  1. On identifie a, b, c
    a=−3b=1c=−2
  2. Discriminant
    Δ=12−4×(−3)×(−2)=1−24=−23
  3. Δ<0
Conclusion
S=∅

Piège : (−3)×(−2)=+6, donc on retranche 4×6=24.

Coefficients fractionnaires †Résoudre 12x2−32x+1=0.
  1. On multiplie tout par 2 pour supprimer les fractions
    x2−3x+2=0
  2. Discriminant
    Δ=(−3)2−4×1×2=9−8=1
  3. Solutions
    x1=3−12=1x2=3+12=2
Conclusion
S={1;2}

Ch1Forme canonique

Deux méthodes : compléter le carré, ou calculer α=−b2a puis β=f(α) (très pratique pour contrôler).

Coefficient entierÉcrire 2x2−8x+1 sous forme canonique.
  1. On factorise a=2 dans les termes en x
    2x2−8x+1=2(x2−4x)+1
  2. On reconnaît le début d'un carré : x2−4x=x2−2×x×2
    =2(x2−2×x×2+22−22)+1
  3. On regroupe le carré
    =2((x−2)2−4)+1
  4. On développe le facteur 2
    =2(x−2)2−8+1
Conclusion
2x2−8x+1=2(x−2)2−7

Contrôle : α=−−84=2 et β=f(2)=8−16+1=−7.

Coefficient fractionnaireÉcrire 3x2−2x+4 sous forme canonique.
  1. On factorise a=3
    3x2−2x+4=3(x2−23x)+4
  2. 23x=2×x×13, donc on complète avec (13)2
    =3(x2−2×x×13+(13)2−(13)2)+4
  3. On regroupe
    =3((x−13)2−19)+4
  4. On développe le facteur 3
    =3(x−13)2−39+4=3(x−13)2−13+4
Conclusion
3x2−2x+4=3(x−13)2+113

Contrôle : α=13 et β=f(13)=13−23+4=113. (Dans le cours la dernière ligne s'arrête à −13 : il faut ajouter le +4.)

Ch1Factoriser un trinôme

Le coefficient a se place toujours devant. Pour une racine x1, le facteur est (x−x1) : racine −1 donne (x+1).

Δ > 0 · avec a ≠ 1Factoriser f(x)=2x2+3x+1.
  1. Discriminant
    Δ=32−4×2×1=9−8=1
  2. Racines
    x1=−3−14=−1x2=−3+14=−12
  3. On applique a(x−x1)(x−x2)
Conclusion
f(x)=2(x+1)(x+12)
Δ > 0 · avec a = 1Factoriser g(x)=x2−6x−7.
  1. Discriminant
    Δ=(−6)2−4×1×(−7)=36+28=64
  2. Racines
    x1=6−82=−1x2=6+82=7
Conclusion
g(x)=(x+1)(x−7)
Δ = 0 · carréFactoriser 4x2−12x+9.
  1. Discriminant
    Δ=144−144=0
  2. Racine double
    x0=−b2a=128=32
Conclusion
4x2−12x+9=4(x−32)2

On peut aussi l'écrire (2x−3)2. Dans le cours le théorème est écrit avec x0=−ba : c'est une erreur, il faut x0=−b2a.

Δ < 0 · impossibleFactoriser x2−2x+3.
  1. Discriminant
    Δ=(−2)2−4×1×3=4−12=−8
  2. Δ<0 : pas de racine réelle
Conclusion
pas de factorisation dans ℝ
Racines évidentesFactoriser f(x)=3x2+3x en cherchant des racines évidentes.
  1. On teste 0
    f(0)=0
  2. On teste −1
    f(−1)=3×(−1)2+3×(−1)=3−3=0
  3. Deux racines trouvées : 0 et −1
Conclusion
f(x)=3(x−0)(x+1)=3x(x+1)

Ch1Somme et produit des racines

Avec une racine évidente r : r×x2=ca et r+x2=−ba (la deuxième égalité sert de contrôle).

Racine évidente · a = 1Résoudre x2+4x−5=0.
  1. Racine évidente
    12+4×1−5=0⇒x1=1
  2. Produit des racines
    P=ca=−5=x2×1⇒x2=−5
  3. Contrôle avec la somme
    S=−ba=−4=1+(−5) ✓
Conclusion
S={−5;1}
Racine évidente · a ≠ 1Résoudre 2x2−x−6=0.
  1. Racine évidente
    2×22−2−6=8−2−6=0⇒x1=2
  2. Produit des racines
    P=ca=−62=−3=2×x2⇒x2=−32
  3. Contrôle avec la somme
    S=−ba=12=2−32 ✓
Conclusion
S={−32;2}
Deux nombres : somme et produitTrouver tous les couples de réels de somme 4 et de produit 1.
  1. Ils sont solutions de x2−Sx+P=0
    x2−4x+1=0
  2. Discriminant
    Δ=16−4=12>012=23
  3. Les deux nombres
    x1=4−232=2−3x2=4+232=2+3
  4. Contrôle
    x1+x2=4x1x2=4−3=1 ✓
Conclusion
(2−3;2+3) et (2+3;2−3)

Ch1Polynôme de degré 3

On cherche une racine évidente r, on écrit P(x)=(x−r)(ax2+bx+c), on trouve a,b,c, puis on factorise le trinôme.

Par identificationFactoriser P(x)=2x3−7x2+2x+3.
  1. Racine évidente
    P(1)=2−7+2+3=0⇒1 est une racine
  2. On pose
    P(x)=(x−1)(ax2+bx+c)
  3. On développe
    (x−1)(ax2+bx+c)=ax3+(b−a)x2+(c−b)x−c
  4. Identification avec 2x3−7x2+2x+3
    a=2b−a=−7c−b=2−c=3
  5. On résout
    a=2b=−5c=−3
  6. Trinôme 2x2−5x−3 : Δ=25+24=49
    x1=5−74=−12x2=5+74=3
Conclusion
P(x)=2(x−1)(x+12)(x−3)

Ch1Changements de variable

Toujours revenir à x à la fin, et vérifier les conditions sur la nouvelle variable.

Bicarrée · une valeur de X utileRésoudre x4+3x2−4=0.
  1. On pose X=x2 (avec X≥0)
    X2+3X−4=0
  2. Discriminant
    Δ=9+16=25X1=−3−52=−4X2=−3+52=1
  3. X=−4 : impossible
    x2=−4<0
  4. X=1 : deux solutions
    x2=1 ⇒ x=1 ou x=−1
Conclusion
S={−1;1}
Bicarrée · aucune solutionRésoudre x4+2x2+1=0.
  1. On pose X=x2
    X2+2X+1=0
  2. Discriminant
    Δ=4−4=0X=−1
  3. X<0 : impossible
    x2=−1<0
Conclusion
S=∅
Irrationnelle · X = √xRésoudre −x+x+3=0.
  1. On pose X=x (donc X≥0 et x=X2)
    −X2+X+3=0
  2. Discriminant
    Δ=1+12=13
  3. Les deux valeurs de X
    X1=−1−13−2=1+132X2=−1+13−2=1−132
  4. X2<0 car 13>1 : on l'élimine ; on garde X1>0
  5. On revient à x=X12
    x=(1+132)2=1+213+134=7+132
Conclusion
S={7+132}
√ = expression †Résoudre x+3=x−1.
  1. Conditions
    x+3≥0 et x−1≥0 ⇒ x≥1
  2. On élève au carré
    x+3=(x−1)2=x2−2x+1
  3. Tout à gauche
    x2−3x−2=0
  4. Discriminant
    Δ=9+8=17x1=3−172≈−0,56x2=3+172≈3,56
  5. On vérifie les conditions : x1<1 est rejetée, x2≥1 est conservée
Conclusion
S={3+172}
